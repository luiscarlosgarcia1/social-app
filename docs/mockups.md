# Wireframes / Mockups

These are low-fidelity wireframes represented in plain Markdown using ASCII. Markdown can hold this reliably. It cannot produce a true visual mockup by itself unless you embed images or use HTML/CSS, so these should be treated as structural wireframes rather than polished UI comps.

## 1. Login Page

```text
+--------------------------------------------------+
|                  UTRGV Match                     |
|         Sign in to find your project partner     |
|                                                  |
|  [ Email                                      ]  |
|  [ Password                                   ]  |
|                                                  |
|  [                 Login                     ]   |
|                                                  |
|  Don't have an account? Register here            |
+--------------------------------------------------+
```
